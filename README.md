# Study Builder — PWA prototype

Android向けPWAの初期実装です。勉強タイマー、目標時間、進捗に応じた建築レイヤー表示、学習記録、端末内保存を備えています。

## 起動方法

ES ModulesとService Workerを使うため、`index.html`を直接開くのではなくHTTP(S)で配信してください。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。Android端末ではHTTPSで公開したURLをChromeで開き、「ホーム画面に追加」からインストールできます。

## 操作

- 「勉強を開始」でタイマー開始。停止中は建設進捗は増えません。
- 一時停止・再開に対応。実行中にアプリを閉じても開始時刻から経過時間を復元します。
- 25 / 50 / 90 / 120分のプリセット、任意時間の設定が可能です。
- 3Dビューはドラッグで回転、ピンチ／ホイールで拡大縮小できます。
- 進捗は20 / 40 / 65 / 85%で城壁・街並み・修道院・尖塔が順に表示されます。
- 学習記録とプロジェクト状態はlocalStorageに保存されます。

## 現時点の範囲・注意

- 3DモデルはThree.jsで構成した初期ジオラマです。史実に基づく配置・寸法の精密なアセット制作は今後の工程です。
- Three.jsとOrbitControlsはjsDelivr CDNから読み込むため、初回起動時はインターネット接続が必要です。シェル自体はService Workerでキャッシュしますが、3Dライブラリの完全なオフライン同梱は未実装です。
- 保存先はブラウザ内のlocalStorageです。ブラウザデータ消去や端末移行に備えたエクスポート／同期機能は未実装です。
- タイマーは端末時刻に依存します。端末の時計を変更した場合の補正機能は未実装です。
